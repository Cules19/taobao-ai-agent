## 学习总结

- **Function Calling 不是执行函数。** 模型输出函数名和 JSON 参数，Python 确认工具白名单和输入后执行，再将结果发给模型。
- **测试和真实联调证明不同的事。** 业务测试能核对数据、筛选和排序；无凭据的协议测试能核对客户端发出的消息；只有真实联调才能检验模型是否愿意正确选择工具及账户是否可用。
- **上下文也要保持结构。** 留下 `assistant` 的调用而裁掉对应 `tool` 结果，会破坏回填关系。项目按完整的一轮保存和裁剪。
- **提示词不能代替业务校验。** 订单格式、金额和收藏目标由服务端检查。响应异常时给明确提示，把错误类型和耗时留在终端。
